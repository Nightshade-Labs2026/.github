# Nightshade Labs 🛡️

> *Independent AI & Security Research Collective*

Nightshade Labs is an open-source research group focused on LLM security, red-teaming methodologies, structural model teardowns, and reproducible evaluation frameworks. 

## 🔬 Research Focus Areas
- **LLM Security & Red-Teaming:** Investigating prompt injection vectors, agentic tool-use security, and alignment robustness.
- **Architectural Teardowns:** Analyzing tokenization mechanics, memory overhead, and structural quirks of newly released open and closed models.
- **Open Benchmark Suites:** Building reproducible, command-line-driven evaluation tools for the security community.
