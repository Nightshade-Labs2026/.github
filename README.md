## ⚡ Mission Statement

**Nightshade Labs** is an independent open-source research collective dedicated to deconstructing frontier AI models and dissecting emerging attack surfaces in LLMs and Autonomous Agents.

We publish **rapid model teardowns**, **security evaluation suites**, and **peer-reviewed preprints** covering:
- Indirect & Direct Prompt Injection Mechanics
- Autonomous Agent Tool-Use Vulnerabilities
- Mechanistic Interpretability & Safety Probes
- Open Evaluation Benchmarks & Red-Teaming Suites

## 🔬 Core Research Vectors

<details open>
<summary><b>1. 🛡️ Adversarial Security & Red-Teaming</b></summary>
<br>

Focusing on the discovery of jailbreak vectors, jailbreak robustness benchmarks, instruction hierarchy bypasses, and security bounds for multi-modal model APIs.
</details>

<details open>
<summary><b>2. 🧩 Architectural Teardowns & Mechanics</b></summary>
<br>

Conducting deep-dive structural analyses on newly released weights—inspecting tokenizer anomalies, context decay profiles, attention layer behaviors, and inference bottlenecks.
</details>

<details>
<summary><b>3. 🧪 Open-Source Security Tooling</b></summary>
<br>

Developing developer-first Python packages, model probes, and command-line interfaces for real-time security scanning and red-team evaluation.
</details>
